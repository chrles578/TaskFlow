**📝** **TaskFlow**

TaskFlow is a dynamic, customizable to-do list application designed to help you organize your daily tasks, capture detailed notes, and personalize your workspace to fit your mood.

Built from a simple idea—a to-do list that goes beyond just checking boxes—TaskFlow allows you to add context to your tasks via integrated notes and change the app's background colors to create your ideal productivity environment.
✨ Features

    Core Task Management: Easily add, complete, and delete tasks from your daily list.
    Integrated Notes: Don't just list a task; explain it. Attach detailed notes to individual to-dos so you never forget the specifics.
    Customizable Backgrounds: Change the background color of the application to suit your preference, reduce eye strain, or color-code your productivity sessions.
    Intuitive UI: A clean, user-friendly interface designed to keep you focused on what needs to be done.

🛠️ How to Use

    Add a Task: Type your task into the input bar and press Enter.
    Add a Note: Click on a created task (or its specific note icon) to open a text area where you can type detailed instructions, links, or reminders.
    Change Theme: Click the color palette/settings icon to cycle through or select a new background color for the app.
    Complete a Task: Check the box next to a task to mark it as done!
